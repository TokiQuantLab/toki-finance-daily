# 普通浏览补充技术页

来源 URL 与 `config/sources.json` 对应。公开技术页在普通浏览中能正常显示时，用 Agent 已有浏览器工具读取；复用已打开的页面，每个品种每天保留一次正常页面会话。已配置 `browser_timeframes` 的品种在这次会话内依次观察 `30m/1h/5h/1D/1W/1M` 六个免费周期。锁定的 1/5/15 分钟周期跳过。

## 独立读取各周期

每个配置的免费周期最多正常激活一次。页面有普通广告提示时，可用正常界面关闭后操作周期按钮；不重复导航或刷新页面。先确认唯一选中标签确实对应本周期，再等待指标、均线和枢轴点详情改变、四张可见技术表出现真实数值且稳定。只有标签或顶部摘要改变，不能证明详情已经刷新；未完成的周期记为缺口，不复制上一周期数值。

可见 DOM 提取程序在 [investing-visible-capture.js](../../../toki_finance_daily/assets/investing-visible-capture.js)。每个周期就绪后，用浏览器工具的只读 DOM evaluate 执行其函数，保存返回的 HTML 字符串和本次实际读取时刻。函数提取当前品种标题、报价币种、可见周期标签及四张技术表，各表保留自己的时间和总结；周期切换由普通界面操作完成，提取函数只读取当前可见字段。返回 HTML 是派生快照，不含脚本状态、侧栏或 FAQ。

读取脚本后显式调用函数；evaluate 接受表达式字符串时使用 `"(" + captureScript + ")()"`。保存前确认返回值为包含四张表的非空 HTML 字符串，避免只求值函数声明而没有实际执行。

每个周期保留自己的 `observed_at`。来源明确且可信的表时间由解析器写入本表 `provider_at`；未标时间、无法确认或晚于实际观察的时间保持 `provider_at: null`，公开显示“观察时点 … · 来源更新时间未确认”。不同周期、不同表的数值及时间独立，不能用 1h 的 RSI、均线或枢轴点填入日线、周线或月线。

## 保存多周期 bundle

多周期会话保存 UTF-8 JSON，字段如下：

|字段|含义|
|---|---|
|`format` / `version`|固定为 `investing-visible-timeframes` / `1`|
|`source_url`|与本地来源配置的 URL 完全一致|
|`requested_timeframes`|来源配置的免费周期列表，非空、最多六项、不可重复|
|`observed_at`|成功快照中最晚的真实观察时刻，含时区的 ISO 时间|
|`snapshots`|至少一份成功项，每项为 `timeframe`、自身 `observed_at`、可见 `html` 与其 UTF-8 字节的 `sha256`|
|`errors`|未取得周期的真实缺口，每项为 `timeframe` 与最多 300 字符的 `error`|

每个请求周期必须落入成功或缺口其中一项，两者不能重叠。成功项的周期标签必须与该 HTML 实际选中的免费周期一致。程序校验品种、表格形状、数值、周期、时间及哈希后才入库；缺口仅留在私有采集元数据，不填造技术记录。

## 入库与旧输入兼容

CLI `cache-technicals` 的 `--html` 参数同时接受可见 HTML 文件和上述 JSON bundle；`--source-id` 对应配置来源，`--observed-at` 使用真实观察时刻，多周期时采用 bundle 最后一次成功观察时刻。该命令只校验和入库，不请求网络。

程序保存 24 小时缓存，后续 `collect` 复用成功证据。缓存导入不会修改已经生成的 Dataset：本次采集后补充的快照，需要重新 `collect --out <工作目录>`，再 `prepare` 和成稿。当日实时更新让新的截止时刻覆盖本次观察，不沿用首次采集冻结的 `--cutoff`；历史请求仍使用用户指定截止时刻，晚于该边界的快照不会进入 Dataset。最终按新 Dataset 的实际周期明细判断覆盖。

多周期请求与旧单页请求的缓存标识分开，旧单 HTML 不会被误认为六周期会话。bundle 的 `fetched_at` 沿用最后一次真实周期观察，每条记录仍保留自身周期的 `observed_at` 与各表 `provider_at`，不改成导入或再次运行时刻。被补充的失败尝试保留在私有元数据；被替换的旧成功快照留存历史。

旧单 HTML 继续兼容，可保留页面实际可见的六周期评级摘要及当前选中一个周期的三组明细。它不能补齐其他周期的详情，也不能从摘要推断未取得的分项评级。生成新的当期 Dataset 后再编辑和渲染；长图只引用选题需要的证据，完整多周期技术表留在研究网站。

当前允许黄金现货、黄金期货、WTI、Brent、比特币和纳斯达克100六个已核对的技术页面。页面未正常显示、需要付费内容或遇到登录/访问挑战时，保留该页或周期的覆盖缺口。来源未来时钟标签保留原文，仅使用已确认观察时刻，不自行换时区。TradingView 原站可查看品种，不代表其免费外站组件当前有数据；原油与 NDX 的原站观察卡不表示已恢复在线仪表。
